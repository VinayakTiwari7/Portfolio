A clean, high-performance portfolio website built with **React 19**, **Tailwind CSS**, and **Framer Motion** to showcase my work across **AI systems, LLM orchestration gateways, and enterprise backend engineering**.

🌐 **Live Deployment**: [https://portfolio-mu-swart-wruiirtba2.vercel.app/](https://portfolio-mu-swart-wruiirtba2.vercel.app/)

---

## ✨ Features

- **Moody Shady Aesthetic**: Glassmorphism cards, subtle grid backdrops, ambient cyan radial glows, and responsive typography.
- **Canonical Flagship Projects**: Interactive cards with system architecture breakdown modals, category filter tabs (`AI & LLM Engineering` vs `Backend & Full-Stack`), and direct links to live applications, API documentation, and source code.
- **Dual-Track Specialized Resumes**: 1-click downloads for **AI & LLM Systems Resume** and **Backend & Systems Resume** statically served via Vite.
- **Categorized Technical Matrix**: 8 technical competency areas directly reflecting real project stacks.
- **Interactive Contact Hub**: 1-click email clipboard copy helper and direct social links.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

```bash
# Clone repository
git clone https://github.com/VinayakTiwari7/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
